# v2026.1012.0-mikoshi.2

Upstream `paperclipai` **2026.1012.0** (tag `v2026.1012.0`) plus four server fixes from the mikoshi fork. Not published to npm.

## Install

```sh
npm install -g https://github.com/overcuriousity/paperclip/releases/download/v2026.1012.0-mikoshi.2/paperclipai-2026.1012.0-mikoshi.2.tgz
```

## Packaging

- `paperclipai-2026.1012.0-mikoshi.2.tgz` is the CLI. It depends on the forked server by the URL of its release asset, not by a registry version:
  `@paperclipai/server`: `https://github.com/overcuriousity/paperclip/releases/download/v2026.1012.0-mikoshi.2/paperclipai-server-2026.1012.0-mikoshi.2.tgz`
- `paperclipai-server-2026.1012.0-mikoshi.2.tgz` is the forked `@paperclipai/server`, built from branch `mikoshi`.
- All other `@paperclipai/*` dependencies are the unchanged upstream packages. They are pinned to exactly `2026.1012.0` and resolve from the npm registry.
- `SHA256SUMS` lists the checksums of both tarballs.
- Build: `scripts/mikoshi-release.sh <version>`, run by `.github/workflows/mikoshi.yml` (workflow_dispatch with `release`).

## Changes on top of 2026.1012.0

- **MIK-268**: re-admit reassignment handoff wakes lost to the cleanup race. A reassignment could park the new assignee's wake on the stopped run's ownership blocker, and nothing re-admitted it. Upstream reports: #13532, #14537, #15138, #14973.
- **MIK-30**: do not create a board-only replay hold for a run that the stale-queued-run gate cancelled before it started.
- **MIK-137**: record a controller lease loss as `failed / controller_lease_lost` with a conversation continuation and a process-loss retry, instead of `cancelled`, which parked the issue `blocked` with no wake.
- **MIK-288**: do not create a board-only replay hold for a run the queue cancelled before it started (`issue_assignee_changed`, `issue_dependencies_blocked`, `issue_terminal_status`, or any stale-queued-run-gate cancel, with no `startedAt` and no `processPid`). A pre-dispatch review wait (`issue_continuation_waiting_on_review`) keeps upstream's evidence check. Supersedes `v2026.1012.0-mikoshi.1`, which lacks this fix.
